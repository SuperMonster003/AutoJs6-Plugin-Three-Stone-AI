# v1.2.1

###### 2026/09/29

* `提示` 32 位兼容性修改为尚未发布的候选版本. 已执行的检查及未覆盖的设备见 docs/dev/32-bit-compatibility-2026-09-29.md.
* `修复` 宿主传来的工具结果图片以宿主私有缓存中的普通文件描述符交付时, Provider 经 /proc/self/fd 重新打开会因无权遍历宿主目录而失败 (EACCES), 整轮工具续轮以 PROTOCOL_VIOLATION 中止; 现在对普通文件回退为复制描述符直接读取 (普通文件不会阻塞读取), 管道仍使用私有的非阻塞重开描述符. 真机 (Sony XQ-DQ72, AutoJs6 5298, 3-Stove Agent 1.3.0) 上 screen_capture 图片经原生工具结果送入 Codex / Gemini 模型时曾必现此失败
* `修复` 原生工具调用的每一轮工具结果被接受后, 该次生成的超时重新计时: 此前整个工具轮 (包括等待工具结果的时间) 共用首个请求的超时, 超过它的多轮任务一律以 TIMEOUT 结束; 现在只有在未提交结果时才按原超时到期. 与 AutoJs6 宿主和 3-Stove Agent 的同步改动配合
* `修复` 新增 x86 和 armeabi-v7a 安装包以支持在线 AI 及宿主集成; 根据进程架构和已安装的原生库判断本地推理能力, 并在模型管理页说明不可用原因

# v1.2.0

###### 2026/09/26

* `提示` 开发候选版本, 尚未发布. 在线工具调用经 AI Provider V2 提供; Agent 集成需要 build 5297+ 的宿主原生工具代理及支持此能力的 Agent 版本. 插件向宿主返回调用, 自身不执行设备操作.
* `提示` 在 设置 > 在线 AI 中编辑配置并选择支持图片输入的模型. 已有配置默认关闭. 图片仅发送给所选配置的服务. LiteRT 与持久 ai.session 仍仅支持文本; Agent 截图要求 Android 11+, 兼容的 AutoJs6 与 AI Agent, observe 工具组及为所选精确模型启用图片输入.
* `提示` AiGoCode gpt-5.6-sol 已在 Provider 1.2.0 / build 218 通过真实初始图片与工具结果图片探针. 合成图片探针不代表其他目标也支持图片或已通过完整 Agent 视觉任务.
* `新增` 在线 OpenAI 兼容, Anthropic Messages 与 Gemini GenerateContent 目标支持原生工具调用, 包含流式参数, 并行调用与结果续轮
* `新增` 在线模型通过协商 AI Provider 2.1 接收 JPEG/PNG 图片及工具结果图片, 支持按具体模型启用
* `新增` 新增在线预置模型自动更新与手动刷新, 支持本地缓存及离线回退, 保留已保存配置与自定义模型 ID
* `新增` 按厂商分组浏览预置模型, 并扩充 OpenRouter 中的 Qwen, Kimi, GLM, Grok, Meta, MiniMax 等模型选择, 保留准确的模型 ID
* `修复` 描述符读取在取消或超时后释放工作线程, 并保留可靠管道的生产者错误
* `修复` 通过 AI Provider 回调保留固定的在线失败分类, 不暴露请求或响应内容, 不增加自动重试
* `修复` 修复 IntelliJ IDEA F10 运行时 No APK found 错误, 按构建变体读取 AGP 实际 APK 目录, 保留 16 KB 对齐检查
* `优化` 根据官方目录更新在线预置模型, 包含 Claude Fable 5.1 等当前模型并移除已停用的模型 ID, 保留已有配置与自定义模型

# v1.1.0

###### 2026/09/01

* `新增` 应用及运行时统一命名为 3-Stone AI, 同步组件, 插件发现及安装包标识
* `新增` AI Provider 公共契约, 统一使用 ai-provider-api 及 org.autojs.plugin.AI_PROVIDER (不保留旧标识别名)
* `新增` 宿主可直接打开的插件设置入口, 受签名权限保护
* `新增` AI Provider V2 分页目标目录, 支持 local:* 本地模型及 profile:* 在线配置, 提供能力, 可用状态, 限制及默认目标信息
* `新增` temperature/topK/topP/maxTokens 生成参数, 支持 LiteRT-LM 采样及输出长度设置
* `新增` 生成用量及耗时统计, 支持通过 ai.chat().usage 及流式事件获取输入, 输出和总 token 数
* `新增` AI Provider V2 持久会话, 支持通过 ai.session 复用多轮对话而无需重复传入历史
* `新增` structuredJson/responseSchema 结构化输出, 支持 LiteRT-LM 原生 JSON Schema 约束, 流式输出及持久会话
* `新增` CPU/GPU/NPU 后端选择及设备兼容性查询, 不可用时明确报错 (GPU 需要通过 OpenCL 检测, NPU 暂不可用)
* `新增` LiteRT Community 推荐模型下载, 支持选择保存位置, 进度, 取消, 完整性校验及下载后导入
* `新增` 独立聊天界面, 支持流式 Markdown, 历史保存, 消息编辑及搜索
* `新增` 主题色, 夜间模式, 语言, 应用信息及发行历史设置, 可跟随 AutoJs6 的选项默认跟随宿主
* `新增` 字体大小, Enter 键行为, 输出 token 上限及 temperature/topK/topP 等会话设置
* `新增` 支持在流式输出中渲染内联 `$\text{...}$` 内容, 并适配常用数学命令, 上标与下标样式
* `新增` 基于 Android Keystore 的凭据存储, 采用 AES-256-GCM 加密, 仅向调用方提供配置状态
* `新增` 在线服务配置管理, 仅接受 HTTPS 地址, 更换服务或来源时要求重新设置凭据
* `新增` OpenAI Compatible 在线后端, 支持自定义 HTTPS 地址, 凭据及模型, SSE/JSON 响应, 取消, 用量统计, 多轮历史及 JSON Schema, 已配置目标可通过 AI Provider V2 调用
* `新增` OpenAI/Anthropic/Gemini/DeepSeek/OpenRouter 预设, 兼容 OpenAI 协议并适配 Anthropic Messages 及 Gemini GenerateContent 原生接口 (不在协议或本地/在线后端间自动回退)
* `新增` 在线服务设置, 支持配置增删改, API Key 替换及清除, 默认目标, 计量网络开关及连接测试 (测试上限 120 秒, 支持取消)
* `新增` 聊天目标选择器, 支持本地及在线模型, 携带已有上下文切换目标时显示确认提示
* `新增` 每条回复保存生成目标, 重新生成时使用原目标, 目标变化或不可用时明确报错
* `新增` 生成失败时保留部分输出并显示原因, 支持手动切换目标 (不自动切换本地或在线服务)
* `修复` 使用示例设置过小的默认输出限制问题, 未指定 maxTokens 时使用模型默认值, Binder 示例采用完整的 64 KiB 输出额度

# v1.0.0

###### 2026/08/08

* `新增` 设备端 AI 插件, 插件标识为 three-stone-ai, 提供方标识为 autojs6.three-stone-ai
* `新增` 基于 LiteRT-LM 的 CPU 文本生成, 支持多角色历史及可控制速率的流式输出
