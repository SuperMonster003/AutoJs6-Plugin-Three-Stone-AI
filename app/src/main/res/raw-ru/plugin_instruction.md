3-Stone AI добавляет в AutoJs6 чат с ИИ и управление моделями: локальные модели работают на телефоне без сети, а онлайн-сервисы (например, OpenAI, Anthropic, Gemini) используют ваш собственный ключ API. У плагина есть свой экран чата, и он же предоставляет модели модулю `ai` в скриптах AutoJs6.

### Начало работы

1. Откройте 3-Stone AI значком на главном экране, в меню экрана чата нажмите "Настройки", затем "Модели и сервисы".
2. Для локальной модели нажмите "Скачать модель" в разделе "Локальные модели" и выберите рекомендуемую модель; после загрузки и проверки она импортируется автоматически. Если у вас уже есть файл `.litertlm`, нажмите "Импорт файла модели".
3. Для онлайн-сервиса нажмите "Добавить сервис" в разделе "Онлайн-сервисы", выберите поставщика, введите ID модели и ключ API и сохраните. Затем в меню сервиса можно выбрать "Проверить подключение".
4. Вернитесь на экран чата, нажмите название модели вверху, чтобы выбрать модель, введите вопрос и отправьте его.

### Основные возможности

- **Чат**: беседы сохраняются автоматически, можно показать рассуждения модели; при повторной генерации или правке сообщения сохраняются все версии, между которыми можно переключаться.
- **Вложения**: нажмите "+" слева от поля ввода, чтобы добавить изображения, текстовые файлы или PDF. Изображения отправляются моделям, у которых включен "Ввод изображений", PDF - только сервисам Anthropic и Gemini; локальные модели пока не поддерживают вложения.
- **Смена модели**: модель можно сменить в любой момент во время чата; скрипты используют "Цель по умолчанию" со страницы "Модели и сервисы".
- **Управление моделями**: проверяйте, переименовывайте и удаляйте модели в разделе "Локальные модели". Ключи API хранятся только на устройстве и не попадают в экспорт сервисов.
- **Голос**: нажмите микрофон для диктовки, удерживайте его, чтобы начать голосовой диалог, а удерживая ответ, выберите "Озвучить"; с установленным 3-Macaw Speech диктовка и озвучивание работают без сети.
- **Экспорт и отправка**: в меню экрана чата выберите "Экспорт в Markdown" или "Поделиться изображением".

### Использование в скриптах

Скрипты AutoJs6 обращаются к плагину через модуль `ai`. Без указания цели используется "Цель по умолчанию":

```js
ai.ask('Introduce AutoJs6 in one sentence.').then((text) => {
    console.log(text);
});
```

Чтобы закрепить определенную модель, найдите ее цель через `ai.catalog()` и передайте ее `id` в `target`. Пример ниже использует первую доступную локальную модель:

```js
ai.catalog().then((catalog) => {
    let target = catalog.targets.find((item) => item.available && item.locality === 'local');
    if (!target) throw new Error('No available local model');
    return ai.ask('Reply with OK.', { target: target.id, temperature: 0.7 });
}).then((text) => console.log(text));
```

Для многоходового диалога используйте `ai.session`, отправляйте на каждом ходу только новый запрос и по завершении вызовите `session.close()`:

```js
ai.session({ system: 'Keep every answer short.' }).then((session) => {
    return session.ask('Remember this code: Orion.')
        .then(() => session.ask('What code should you remember?'))
        .then((text) => {
            console.log(text);
            session.close();
        }, (error) => {
            session.close();
            throw error;
        });
});
```

- `ai.chat` возвращает полный ответ вместе с расходом токенов, а `ai.stream` возвращает текст по мере генерации.
- `temperature`, `topK`, `topP` и `maxTokens` управляют выборкой и длиной ответа; если цель поддерживает структурированный вывод, передача `responseSchema` возвращает текст, соответствующий этой JSON Schema.
- Если цель недоступна или не настроена, запрос сразу завершается ошибкой (например, `TARGET_UNAVAILABLE`) и не переключается на другую модель.

### Требования

- Android 7.0 или новее, AutoJs6 6.8.0 или новее.
- Для локальных моделей нужно 64-битное устройство (arm64-v8a или x86_64) и достаточно места; окно подтверждения загрузки показывает минимальный объем памяти. На 32-битных устройствах доступны только онлайн-сервисы.
- Для онлайн-сервисов нужен ваш собственный ключ API, поставщик может взимать плату за использование.
- Разрешение на доступ к сети используется для загрузки моделей, обращения к онлайн-сервисам и обновления списка предустановленных моделей; локальный вывод сеть не использует. Плагин не запрашивает разрешения на хранилище и микрофон.

### Частые вопросы

**Различия между локальными моделями и онлайн-сервисами**

Локальные модели работают на телефоне, поэтому беседы не покидают устройство, но скорость и качество зависят от телефона. Онлайн-сервисы отправляют беседы выбранному поставщику и требуют сети и ключа API.

**Причины, по которым после ошибки не выбирается другая модель**

Запросы используют только выбранную вами модель, чтобы беседы не отправлялись в другой сервис без вашего ведома. При ошибке проверьте эту модель в "Модели и сервисы" или смените модель вручную.

**Случаи, когда локальная модель не запускается**

Откройте меню этой модели в разделе "Локальные модели" и нажмите "Проверить модель", чтобы узнать причину; если не хватает памяти, используйте рекомендуемую модель поменьше.

**Случаи, когда другие приложения запрашивают доступ к ИИ**

Прежде чем приложение, собранное в AutoJs6 и подписанное отдельно, сможет использовать ИИ, 3-Stone AI попросит вас подтвердить доступ. Разрешенное приложение может использовать локальные модели и сохраненные онлайн-сервисы, что может расходовать платную квоту; отозвать доступ можно в "Настройки > Конфиденциальность и разрешения > Приложения с доступом к ИИ".

Все параметры, события и коды ошибок описаны в главе [Искусственный интеллект (ИИ)](https://docs.autojs6.com/#/ai) документации AutoJs6, а конфиденциальность и ограничения - на [странице проекта](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI).
