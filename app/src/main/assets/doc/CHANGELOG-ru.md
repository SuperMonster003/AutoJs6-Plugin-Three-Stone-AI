# v1.1.0

###### 2026/08/24

* `Функция` Бренд и идентификаторы среды выполнения официального локального ИИ-плагина AutoJs6 окончательно унифицированы как 3-Stone AI
* `Функция` Межпроцессная интеграция использует нейтральные идентификаторы `ai-provider-api`, `org.autojs.plugin.ai.provider.api`, `org.autojs.plugin.AI_PROVIDER` и `IAiProvider`/`IAiSession`/`IAiCallback` без сохранения псевдонимов замененных идентификаторов
* `Функция` Совместимость с сокращенным селектором `plugin: true` для `ai.ask`/`ai.chat`/`ai.stream` и перечислением моделей `ai.models` в AutoJs6
* `Функция` Передача `temperature`, `topK`, `topP` и `maxTokens` через протокол AI Provider 1.1 в параметры sampling и ограничения выходных tokens LiteRT-LM
* `Функция` Возврат точных количеств входных, выходных и общих токенов LiteRT-LM вместе с измеренной провайдером длительностью генерации через `ai.chat().usage` и потоковые события usage
* `Функция` Постоянные сеансы протокола AI Provider 1.2 и повторное использование многоходового Conversation через `ai.session` AutoJs6 без повторной передачи предыдущей истории
* `Функция` Нативное декодирование LiteRT-LM с ограничением JSON Schema через `structuredJson` и `responseSchema` AutoJs6 для одиночных вызовов, потокового вывода и постоянных сеансов со строгой проверкой завершенного JSON
* `Функция` Явные backend profile `cpu`, `gpu` и `npu` через протокол 1.3 и параметры генерации AutoJs6, с отчетом о совместимости устройства, раздельным кэшем для модели/profile и без отката с недоступных profile; GPU объявляется только после успешной проверки загрузки OpenCL, а NPU остается недоступным из-за отсутствия EAP runtime в пакете
* `Функция` Прямая загрузка закреплённых моделей LiteRT Community в выбранное место SAF с прогрессом, точной отменой, очисткой неполного файла, проверкой заголовка LiteRT-LM, размера и SHA-256 и последующим прямым импортом
* `Функция` Добавлено запускаемое рабочее пространство чата с потоковым Markdown, постоянной историей, предупреждением о замене ветки при редактировании старого сообщения, поиском по нескольким результатам и вводом с учётом клавиатуры
* `Функция` Добавлены настройки приложения для цвета темы, тёмного режима, языка, сведений о приложении и разработчике и истории версий, с вариантом Следовать AutoJs6 по умолчанию там, где это возможно
* `Функция` Добавлены настройки чата для размера шрифта, поведения Enter, неограниченного или заданного числа output token и стандартных для модели или пользовательских `temperature`, `topK` и `topP`
* `Функция` Добавлен потоковый рендеринг встроенного содержимого `$\text{...}$`, распространённых математических команд, верхних и нижних индексов
* `Функция` Добавлено управляемое плагином хранилище учётных данных Android Keystore с AES-256-GCM, аутентифицированным шифротекстом, привязанным к profile, атомарными приватными файлами между процессами, проверкой только состояния configured и немедленным обнулением открытого текста
* `Функция` Добавлено строгое хранилище онлайн-profile без секретов для OpenAI Compatible endpoint только по HTTPS, с каноническими UUID, атомарными межпроцессными метаданными и обязательной явной заменой или очисткой учётных данных при смене provider или origin
* `Функция` Добавлен внутренний OpenAI Compatible HTTPS backend плагина для profile с настраиваемыми baseUrl, учётными данными и моделью, с ограниченным SSE и JSON fallback streaming, точной отменой, provider usage, постоянной историей только завершённых ходов, mapping запросов JSON Schema и фиксированными ошибками без чувствительных данных; маршрутизация хоста AI Provider V1 по-прежнему публикует только локальные target
* `Функция` Добавлены предустановки OpenAI, Anthropic, Gemini, DeepSeek и OpenRouter, согласованные с каталогом хоста; единый слой онлайн-выполнения повторно использует OpenAI-compatible протокол и отдельно адаптирует нативные аутентификацию, запросы, завершение SSE, usage и JSON Schema для Anthropic Messages и Gemini GenerateContent без fallback между протоколами или между локальным и онлайн-режимами
* `Функция` Добавлен интерфейс онлайн-сервисов на 10 языках для создания, изменения и удаления профилей, замены и удаления ключей API без показа, выбора цели по умолчанию, обязательного разрешения тарифицируемой сети до доступа к учетным данным и явных отменяемых проверок подключения до 120 секунд; настройки используют общий атомарный межпроцессный документ, а AI Provider V1 остается только локальным
* `Исправление` Удалены неявные ограничения вывода в 256 токенов и 4 KiB из исполняемых примеров: при отсутствии `maxTokens` теперь используется значение по умолчанию модели или движка, а прямой пример Binder использует полный допустимый объём вывода провайдера 64 KiB
* `Исправление` Исправлен низкоуровневый пример Binder в локализованных на 10 языков инструкциях: он всё ещё вызывал 14-аргументный конструктор `AiGenerationOptions` протокола 1.1 и завершался ошибкой с API протокола 1.3
* `Исправление` Исправлено сохранение цветов текста светлой темы в менеджере моделей при системной тёмной теме, из-за чего текст, флажки и строки моделей были нечитаемы на тёмном фоне
* `Исправление` Поле ввода остаётся над экранной клавиатурой, цвет текста кнопки отправки выбирается по контрасту с темой, а кнопки поиска назад, вперёд и закрытия унифицированы
* `Исправление` Исправлена взаимная блокировка при close session из callback listener генерации, когда ожидание quiescence бесконечно ждало собственный callback; close по-прежнему ожидает callback, уже выполняющиеся в других потоках
* `Исправление` Исправлен ошибочный отказ в приватном хранилище онлайн-profile и учётных данных, когда Android канонизирует доверенный корень данных приложения `/data/user/0` в `/data/data`; прямые дочерние ссылки и выходы за пределы хранилища по-прежнему отклоняются
* `Улучшение` Обновлены описание плагина, инструкция и README на 10 языках в соответствии с формализованным маршрутом `ai.*` локального плагина
* `Улучшение` ROADMAP переписан как дорожная карта функций с независимо проверяемыми пунктами
* `Улучшение` Пунктуация в приложении и сгенерированных локализованных текстах приведена к ASCII и защищена регрессионным тестом
* `Улучшение` Введен общий слой `AiBackend`/`AiTarget`/`AiBackendSession`, благодаря которому чат launcher и Binder provider используют единый путь `LiteRtLocalBackend` для каталога, возможностей, создания сессии, streaming и отмены
* `Улучшение` Локальные target `local:*` и онлайн-target `profile:*` объединены в единый каталог и диспетчер уровня Application; список моделей V1 остаётся только локальным, а онлайн-target честно помечаются unavailable до реализации транспорта выполнения HTTPS

# v1.0.0

###### 2026/08/08

* `Функция` Локальный provider протокола AI Provider V1 с ID и движком `three-stone-ai`, provider ID `autojs6.three-stone-ai` и вариантом `default`
* `Функция` Генерация обычного текста LiteRT-LM только на CPU с историей system, user и assistant и потоком под управлением credits
* `Функция` Импорт `.litertlm` через SAF в закрытое хранилище с пределом 8 GiB, резервом места, SHA-256, fsync и атомарной активацией
* `Функция` Один активный сеанс, ограниченный I/O, квоты дескрипторов, отмена, timeout, одно конечное состояние и проверка вызывающего AutoJs6 с той же подписью
* `Функция` Явное отсутствие возможностей reasoning, tools, structured JSON, usage, сети и credential
* `Функция` APK arm64-v8a, x86_64 и universal с README, changelog, интерфейсом Android и инструкциями плагина на 10 языках
* `Функция` Экран управления моделями для просмотра полного каталога и занятого места в закрытом хранилище, с атомарным выбором текущей модели без копирования файлов моделей
* `Улучшение` Сохранение предыдущих поколений моделей с именами по hash SHA-256 после импорта с заменой для предотвращения межпроцессных гонок с `:provider`, при этом файлы продолжают занимать закрытое хранилище
* `Улучшение` Добавлены координатор одного импорта на уровне приложения и синхронизированный через fsync pending journal для продолжения при пересоздании Activity, восстановления при холодном запуске, очистки stale временных файлов и удаления только destination текущей попытки, которые никогда не публиковались, с сохранением опубликованных, current и исторических поколений с hash
* `Зависимость` Добавлен LiteRT-LM 0.15.0 для генерации текста на CPU устройства
