⁨3-Stone AI⁩ تضيف إلى AutoJs6 المحادثة مع الذكاء الاصطناعي وإدارة النماذج: تعمل النماذج المحلية على الهاتف دون اتصال, وتستخدم الخدمات عبر الإنترنت (مثل OpenAI و Anthropic و Gemini) مفتاح API الخاص بك. للإضافة واجهة محادثة خاصة بها, كما توفر النماذج لوحدة `ai` في سكربتات AutoJs6.

### البدء

1. افتح ⁨3-Stone AI⁩ من أيقونتها على الشاشة الرئيسية, واضغط "الإعدادات" في قائمة صفحة المحادثة, ثم "النماذج والخدمات".
2. لاستخدام نموذج محلي, اضغط "تنزيل نموذج" في قسم "النماذج المحلية" واختر نموذجا موصى به; يستورد تلقائيا بعد تنزيله والتحقق منه. إذا كان لديك ملف `.litertlm`, فاضغط "استيراد ملف نموذج".
3. لاستخدام خدمة عبر الإنترنت, اضغط "إضافة خدمة" في قسم "الخدمات عبر الإنترنت", واختر المزود, وأدخل معرف النموذج ومفتاح API ثم احفظ. بعد ذلك يمكنك اختيار "اختبار الاتصال" من قائمة الخدمة.
4. ارجع إلى صفحة المحادثة, واضغط اسم النموذج في الأعلى لاختيار نموذج, ثم اكتب سؤالك وأرسله.

### الميزات الرئيسية

- **المحادثة**: تحفظ المحادثات تلقائيا ويمكن عرض استدلال النموذج; وعند إعادة توليد رسالة أو تعديلها تبقى كل النسخ ويمكنك التنقل بينها.
- **المرفقات**: اضغط "+" بجوار مربع الإدخال لإضافة صور أو ملفات نصية أو ملفات PDF. ترسل الصور إلى النماذج التي فعل فيها "إدخال الصور", وترسل ملفات PDF إلى خدمات Anthropic و Gemini فقط; ولا تدعم النماذج المحلية المرفقات بعد.
- **تبديل النموذج**: بدل النموذج في أي وقت أثناء المحادثة; وتستخدم السكربتات "الهدف الافتراضي" في صفحة "النماذج والخدمات".
- **إدارة النماذج**: افحص النماذج أو أعد تسميتها أو احذفها في قسم "النماذج المحلية". تحفظ مفاتيح API على الجهاز فقط ولا تدخل في تصدير الخدمات.
- **ترويسات الطلب**: أضف ترويسات طلب مخصصة من "ترويسات الطلب" في صفحة تفاصيل الخدمة, مثل ترويسة الجلسة التي يتطلبها OpenCode Go; تحفظ القيم السرية على الجهاز فقط ولا تدخل في التصدير.
- **الصوت**: اضغط الميكروفون للإملاء, واضغط عليه مطولا لبدء محادثة صوتية, واضغط مطولا على رد لاختيار "قراءة بصوت عال"; ومع تثبيت ⁨3-Macaw Speech⁩ يعمل الإملاء والقراءة دون اتصال.
- **التصدير والمشاركة**: اختر "تصدير بصيغة Markdown" أو "مشاركة كصورة" من قائمة صفحة المحادثة.

### الاستخدام في السكربتات

تستدعي سكربتات AutoJs6 هذه الإضافة عبر وحدة `ai`. عند عدم تحديد هدف يستخدم "الهدف الافتراضي":

```js
ai.ask('Introduce AutoJs6 in one sentence.').then((text) => {
    console.log(text);
});
```

لتثبيت نموذج معين, ابحث عن هدفه عبر `ai.catalog()` ومرر قيمة `id` الخاصة به في `target`. يستخدم المثال التالي أول نموذج محلي متاح:

```js
ai.catalog().then((catalog) => {
    let target = catalog.targets.find((item) => item.available && item.locality === 'local');
    if (!target) throw new Error('No available local model');
    return ai.ask('Reply with OK.', { target: target.id, temperature: 0.7 });
}).then((text) => console.log(text));
```

للمحادثات متعددة الأدوار استخدم `ai.session`, وأرسل في كل دور الطلب الجديد فقط, واستدع `session.close()` عند الانتهاء:

```js
ai.session({ system: 'Keep every answer short.' }).then((session) => {
    return session.ask('Remember this code: Orion.')
        .then(() => session.ask('What code should you remember?'))
        .then((text) => {
            console.log(text);
            session.close();
        }, (error) => {
            session.close();
            throw error;
        });
});
```

- تعيد `ai.chat` الاستجابة الكاملة مع الاستهلاك, وتعيد `ai.stream` النص أثناء توليده.
- تتحكم `temperature` و `topK` و `topP` و `maxTokens` في أخذ العينات وطول الناتج; وإذا كان الهدف يدعم الناتج المنظم, فإن تمرير `responseSchema` يعيد نصا مطابقا لمخطط JSON Schema هذا.
- إذا كان الهدف غير متاح أو غير مضبوط, يفشل الطلب مباشرة (مثلا `TARGET_UNAVAILABLE`) ولا ينتقل أبدا إلى نموذج آخر.

### المتطلبات

- Android 7.0 أو أحدث, و AutoJs6 6.8.0 أو أحدث.
- تحتاج النماذج المحلية إلى جهاز 64 بت (arm64-v8a أو x86_64) ومساحة تخزين كافية; ويعرض مربع تأكيد التنزيل الحد الأدنى المطلوب من الذاكرة. أما الأجهزة 32 بت فتستخدم الخدمات عبر الإنترنت فقط.
- تحتاج الخدمات عبر الإنترنت إلى مفتاح API الخاص بك, وقد يفرض المزود رسوما على الاستخدام.
- يستخدم إذن الشبكة لتنزيل النماذج والوصول إلى الخدمات عبر الإنترنت وتحديث قائمة النماذج المعدة مسبقا; ولا يستخدم الاستدلال المحلي الشبكة. لا تطلب الإضافة إذن التخزين أو الميكروفون.

### الأسئلة الشائعة

**الفرق بين النماذج المحلية والخدمات عبر الإنترنت**

تعمل النماذج المحلية على الهاتف فلا تغادر المحادثات الجهاز, لكن السرعة والجودة تعتمدان على الهاتف. أما الخدمات عبر الإنترنت فترسل المحادثات إلى المزود المختار وتحتاج إلى شبكة ومفتاح API.

**سبب عدم الانتقال إلى نموذج آخر عند الفشل**

تستخدم الطلبات النموذج الذي اخترته فقط, حتى لا ترسل المحادثات إلى خدمة أخرى دون علمك. عند الفشل افحص ذلك النموذج في "النماذج والخدمات" أو بدل النموذج يدويا.

**حالات تعذر تشغيل نموذج محلي**

افتح قائمة ذلك النموذج في قسم "النماذج المحلية" واضغط "فحص النموذج" لمعرفة السبب; وإذا كانت الذاكرة غير كافية فاستخدم نموذجا موصى به أصغر.

**حالات طلب تطبيقات أخرى استخدام الذكاء الاصطناعي**

قبل أن يتمكن تطبيق محزم بواسطة AutoJs6 وموقع بشكل مستقل من استخدام الذكاء الاصطناعي, تطلب منك ⁨3-Stone AI⁩ تأكيد السماح. يمكن للتطبيق المسموح له استخدام النماذج المحلية والخدمات المحفوظة عبر الإنترنت, وقد يستهلك ذلك حصة مدفوعة; ويمكنك إزالة الإذن من "الإعدادات > الخصوصية والأذونات > التطبيقات المصرح لها بالذكاء الاصطناعي".

**حالات إعادة OpenCode Go للخطأ MissingSessionID**

يتطلب OpenCode Go ترويسة الجلسة x-opencode-session في كل طلب. المس "إضافة ترويسة الجلسة" في شرح الخطأ, أو أضف الإعداد المسبق "جلسة OpenCode Go" من "ترويسات الطلب" في صفحة تفاصيل الخدمة, ثم احفظ وأعد المحاولة.

توجد جميع الخيارات والأحداث ورموز الأخطاء في فصل [الذكاء الاصطناعي (AI)](https://docs.autojs6.com/#/ai) من وثائق AutoJs6, وتوجد تفاصيل الخصوصية والقيود في [صفحة المشروع](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI).
