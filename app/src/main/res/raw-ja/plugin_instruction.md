3-Stone AI は AutoJs6 に AI チャットとモデル管理を提供します. ローカルモデルはスマートフォン上でオフライン実行され, オンラインサービス (OpenAI, Anthropic, Gemini など) は自分の API キーを使います. プラグインには専用のチャット画面があり, AutoJs6 スクリプトの `ai` モジュールにもモデルを提供します.

### はじめに

1. ホーム画面のアイコンから 3-Stone AI を開き, チャット画面のメニューで "設定" をタップしてから "モデルとサービス" をタップします.
2. ローカルモデルを使う場合は, "ローカルモデル" セクションで "モデルをダウンロード" をタップして推奨モデルを選びます. ダウンロードと検証の後に自動でインポートされます. `.litertlm` ファイルが手元にある場合は "モデルファイルをインポート" をタップします.
3. オンラインサービスを使う場合は, "オンラインサービス" セクションで "サービスを追加" をタップし, プロバイダーを選んでモデル ID と API キーを入力して保存します. その後, サービスのメニューで "接続をテスト" を選べます.
4. チャット画面に戻り, 上部のモデル名をタップしてモデルを選び, 質問を入力して送信します.

### 主な機能

- **チャット**: 会話は自動で保存され, モデルの思考過程も表示できます. 再生成や編集をしたメッセージは各バージョンが残り, 切り替えられます.
- **添付ファイル**: 入力欄の左にある "+" をタップして画像, テキストファイル, PDF を追加できます. 画像は "画像入力" がオンのモデルに, PDF は Anthropic と Gemini のサービスにのみ送られます. ローカルモデルはまだ添付ファイルに対応していません.
- **モデルの切り替え**: チャット中いつでもモデルを切り替えられます. スクリプトは "モデルとサービス" 画面の "既定のターゲット" を使います.
- **モデル管理**: "ローカルモデル" セクションでモデルのチェック, 名前の変更, 削除ができます. API キーは端末内にのみ保存され, サービスをエクスポートしても含まれません.
- **リクエストヘッダー**: サービスの詳細画面の "リクエストヘッダー" でカスタムリクエストヘッダーを追加できます (例: OpenCode Go が必要とするセッションヘッダー). 秘密値は端末内にのみ保存され, エクスポートには含まれません.
- **音声**: マイクをタップすると音声入力, 長押しすると音声会話を開始します. 応答を長押しすると "読み上げ" を選べます. 3-Macaw Speech をインストールすると入力欄にリアルタイムで音声入力でき, 音声会話でも認識画面が開かず, 音声入力と読み上げをオフラインで行えます.
- **エクスポートと共有**: チャット画面のメニューで "Markdown でエクスポート" または "画像として共有" を選びます.

### スクリプトでの使い方

AutoJs6 スクリプトからは `ai` モジュールでこのプラグインを呼び出します. ターゲットを指定しない場合は "既定のターゲット" が使われます:

```js
ai.ask('Introduce AutoJs6 in one sentence.').then((text) => {
    console.log(text);
});
```

特定のモデルに固定するには, `ai.catalog()` でターゲットを探し, その `id` を `target` に渡します. 次の例は最初に見つかった利用可能なローカルモデルを使います:

```js
ai.catalog().then((catalog) => {
    let target = catalog.targets.find((item) => item.available && item.locality === 'local');
    if (!target) throw new Error('No available local model');
    return ai.ask('Reply with OK.', { target: target.id, temperature: 0.7 });
}).then((text) => console.log(text));
```

複数ターンの会話には `ai.session` を使い, 各ターンでは新しいプロンプトだけを送り, 終わったら `session.close()` を呼び出します:

```js
ai.session({ system: 'Keep every answer short.' }).then((session) => {
    return session.ask('Remember this code: Orion.')
        .then(() => session.ask('What code should you remember?'))
        .then((text) => {
            console.log(text);
            session.close();
        }, (error) => {
            session.close();
            throw error;
        });
});
```

3-Macaw Speech がインストールされている場合, `speech` モジュールで音声入力, 質問, 読み上げをつなげられます. 一文聞き取ったら音声入力を止め, その文字を `ai.chat` に渡し, `speech.speak` で回答を読み上げます:

```js
let session = speech.listen({ timeoutMillis: 8000 });
session.on('final', () => session.stop());
session.on('end', () => {
    let question = session.result();
    if (!question) return;
    ai.chat(question, { maxTokens: 256 })
        .then((response) => speech.speak(response.text))
        .catch((error) => console.error(error.code, error.message));
});
```

- `ai.chat` は使用量を含む完全な応答を返し, `ai.stream` は生成に合わせてテキストを返します.
- `temperature`, `topK`, `topP`, `maxTokens` でサンプリングと出力の長さを調整します. ターゲットが構造化出力に対応している場合, `responseSchema` を渡すとその JSON Schema に沿ったテキストが返ります.
- ターゲットが利用できない, または設定されていない場合, リクエストはそのまま失敗し (例: `TARGET_UNAVAILABLE`), 別のモデルに切り替わることはありません.
- `ai.stream` も `speech.listen` の後に使えます. `done` イベントで `response.text` を読み上げるか, `delta` を文ごとに区切って `speech.speak(sentence, { queue: 'add' })` で生成しながら読み上げます. `speech` モジュールは 3-Macaw Speech が提供し, インストールされていないと呼び出しは失敗します (`PLUGIN_UNAVAILABLE`).

### 動作要件

- Android 7.0 以降, AutoJs6 6.8.0 以降.
- ローカルモデルには 64 ビット端末 (arm64-v8a または x86_64) と十分なストレージが必要です. ダウンロードの確認画面に必要な最小メモリが表示されます. 32 ビット端末ではオンラインサービスのみ使えます.
- オンラインサービスには自分の API キーが必要で, プロバイダーの料金が発生する場合があります.
- ネットワーク権限はモデルのダウンロード, オンラインサービスへの接続, プリセットのモデル一覧の更新に使います. ローカル推論はネットワークを使いません. ストレージやマイクの権限は要求しません.

### よくある質問

**ローカルモデルとオンラインサービスの違い**

ローカルモデルはスマートフォン上で動くため会話が端末の外に出ませんが, 速度と品質は端末の性能に左右されます. オンラインサービスは選んだプロバイダーに会話を送るため, ネットワークと API キーが必要です.

**失敗しても別のモデルに切り替えない理由**

知らないうちに会話が別のサービスへ送られることのないよう, リクエストは選んだモデルだけを使います. 失敗した場合は "モデルとサービス" でそのモデルを確認するか, 手動で切り替えてください.

**ローカルモデルが動かない場合の対処**

"ローカルモデル" セクションでそのモデルのメニューを開き, "モデルをチェック" をタップして原因を確認します. メモリが足りない場合は, より小さい推奨モデルを使ってください.

**他のアプリが AI の利用を求める場合**

AutoJs6 でパッケージ化して個別に署名したアプリが AI を使う前に, 3-Stone AI が許可の確認を求めます. 許可したアプリはローカルモデルと保存済みのオンラインサービスを使え, 有料の利用枠を消費することがあります. 許可は "設定 > プライバシーと権限 > AI アクセスを許可したアプリ" で取り消せます.

**OpenCode Go が MissingSessionID を返す場合**

OpenCode Go はすべてのリクエストにセッションヘッダー x-opencode-session を求めます. エラーの説明で "セッションヘッダーを追加" をタップするか, サービスの詳細画面の "リクエストヘッダー" で "OpenCode Go セッション" プリセットを追加し, 保存してからやり直してください.

すべてのオプション, イベント, エラーコードは AutoJs6 ドキュメントの [人工知能 (AI)](https://docs.autojs6.com/#/ai) 章に, プライバシーと制限は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI) にあります.
